# Mock PTI Service

> **Experimental** local provider emulator for wallet development and testing.

Mock PTI (`mockpti`) is a local stand-in for the PTI/Fiant provider API, used
during development and automated testing.

All implementation phases are complete in this repository.

## Official documentation

`mockpti` is intended to emulate PTI/Fiant provider behavior for local runs.
The official API and platform reference is:

- https://developers.platform.fiant.io/docs

Wallet-specific integration context in this repository:

- `documentation/docs/provider-payments-reference.md`
- `documentation/docs/signup-guide.md`
- `documentation/docs/kyc-guide.md`


## Webhook crypto settings CLI

`mockpti` includes helper CLI commands to generate local webhook JWK settings
for wallet/backend + mockpti, and to derive a public JWK from a private JWK.

Generate a full local key set:

```bash
go run ./cmd/mockpti gen-webhook-settings
```

This command prints ready-to-paste values for:

- `.env` variables (`BACKEND_PTI_JWK`, `BACKEND_PTI_PUBLIC_KEY_JWK`, `MOCKPTI_WEBHOOK_SIGNING_JWK`, `MOCKPTI_WEBHOOK_ENCRYPTION_JWK`)
- `local/wallet.yaml` backend env lines (`PTI_JWK`, `PTI_PUBLIC_KEY_JWK`)
- `local/mockpti.yaml` env lines (`MOCKPTI_WEBHOOK_SIGNING_JWK`, `MOCKPTI_WEBHOOK_ENCRYPTION_JWK`)

Derive public JWK from private JWK JSON on stdin:

```bash
cat private.jwk.json | go run ./cmd/mockpti derive-public-jwk
```

Notes:

- Webhook security is asymmetric, not a shared symmetric secret.
- `mockpti` signs webhook payloads with `MOCKPTI_WEBHOOK_SIGNING_JWK` and encrypts
	to the backend decrypt key (`MOCKPTI_WEBHOOK_ENCRYPTION_JWK`).
- Backend verifies signatures with `PTI_PUBLIC_KEY_JWK` and decrypts with
	`PTI_JWK`.

## Wallet integration

When landing this work as two separate PRs, treat `mockpti` and `wallet` as
independent deliverables that are wired together by env/config only.

- Add or update mockpti webhook security behavior (sign + encrypt webhooks).
- Keep local integration helpers in place (`gen-webhook-settings`,
	`derive-public-jwk`).
- Include tests proving the webhook crypto roundtrip (sign/encrypt and
	decrypt/verify).
- Update local compose config (`local/wallet.yaml`, `local/mockpti.yaml`) with
	values generated by:

```bash
go run ./cmd/mockpti gen-webhook-settings
```

- Ensure these values are wired:
	`PTI_JWK`, `PTI_PUBLIC_KEY_JWK`,
	`MOCKPTI_WEBHOOK_SIGNING_JWK`, `MOCKPTI_WEBHOOK_ENCRYPTION_JWK`.
- Keep `PTI_BASE_URL` compatible with backend Fiant controller allowlist for
	local runs.

Recommended local verification after wiring:

1. Start local stack (`make all-nowatch` from `local/`).
2. Complete mock KYC flow in wallet UI.
3. Confirm logs show webhook delivery + backend webhook acceptance.
4. Confirm user progresses past pending KYC state.
